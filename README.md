The project contains a simple menu-based interface with the following options:
- Encrypt
- Decrypt
- Attack
- Analyze
- Exit
The Analyze option reads text files from the datasets folder and provides information such as:

- Total number of characters
- Total number of words
- Total number of lines
- Number of unique characters
- Frequency of each alphabet letter
This feature will be useful for future cryptanalysis experiments.


The log stores:
- Date
- Time
- Selected menu option
The log file is stored inside the logs folder.

The datasets folder contains five sample text files:
- sample1.txt
- sample2.txt
- sample3.txt
- sample4.txt
- sample5.txt
